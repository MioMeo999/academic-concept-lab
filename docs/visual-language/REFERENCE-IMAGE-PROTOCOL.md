# Academic Concept Lab — Reference Image Protocol

Visual references are inspiration, not wireframes. Identify them by visible title/content, not upload order.

## “Material, Pigment & Mark Library”

Highest authority for material language.

Learn from pencil pressure, hatching, cross-hatching, scumble, stipple, smudge, pigment clouds, layered overlaps, ghost construction, partial boundaries, rubbed-out marks, repeated circles, tonal fields, ambiguity and directional force.

Do not copy the grid, sample boxes, exact diagrams or label structure.

This image teaches **how marks behave**.

## “Ideas, drawn together”

High authority for the overall visual world.

Learn from editorial serif typography, clean white canvas, drawing integrated with type, theory-specific composition, selective handwritten intervention, controlled chromatic richness, quiet scholarship and page-wide rhythm.

Do not copy exact page layouts or theory diagrams.

This image teaches **how scholarship and drawing coexist**.

## “Think · Connect · See Theories”

Supporting authority.

Learn from chromatic richness, annotation energy, broad visual vocabulary, conceptual visibility and artistic confidence.

Resist scrapbook tendencies, sticky-note dominance, modular moodboard layout, worksheet feeling and educational-poster aesthetics.

This image teaches **energy and visual abundance**, not page structure.

## Creative assimilation

Ask:
- What material behaviour is useful here?
- What intellectual structure should become visible?
- What drawing would make the idea easier to think with?
- What should remain precise and typeset?
- Where should the page become quiet?

Do not ask which reference layout to copy or which sample diagram to recreate.

## Reference hierarchy

1. Material, Pigment & Mark Library — material behaviour
2. Ideas, drawn together — scholarly visual world
3. Think · Connect · See Theories — energy and richness

Project content and academic source-of-truth always outrank visual references.
