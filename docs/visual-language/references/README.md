# VISUAL REFERENCES, NOT TEMPLATES

This folder is a visual reference library for Academic Concept Lab. These
images are provided to study editorial composition, typography, white space,
graphite, pencil, crayon and dry pigment, paper materiality, marginalia,
annotation, visual rhythm and diagrammatic thinking. They are references for
making decisions, not production assets.

They are **not** templates, mandatory layouts, production screenshots,
finished UI components or a requirement to add artwork to a page.

**THE CONTENT DETERMINES THE GEOMETRY.**

**LEARN THE MATERIAL VOCABULARY. DO NOT COPY THE COMPOSITION.**

Diagram families are prompts for thinking, not presets.

The vocabulary is useful as a set of possibilities: white canvas, graphite,
coloured pencil, dry pigment/crayon, construction lines, handwritten
marginalia, paper fragments, overlap, trace, fade, residue, branch and wave.
These are not universal laws. Use them only when they clarify the knowledge.

Before a major visual design or redesign, read the visual-language documents
and inspect the relevant reference folders. Keep formal scholarship live in
HTML, choose geometry from the content, and treat any authored artwork as a
deliberate art-layer decision rather than decoration.
