# Academic Concept Lab — Visual Review Checklist

Use this after every visual iteration.

## Identity
- [ ] Feels like Academic Concept Lab rather than a generic academic website
- [ ] Contemporary rather than nostalgic
- [ ] White canvas remains visually important
- [ ] Precise underneath, human on top

## Typography
- [ ] Formal scholarship remains clearly typeset
- [ ] Handwriting is selective
- [ ] Typography feels editorial and serious
- [ ] Body text is comfortably readable

## Drawing
- [ ] Drawing is doing intellectual work
- [ ] It is integrated with the page rather than pasted beside it
- [ ] It avoids clean-vector illustration as the default
- [ ] There is enough material variation

## Pigment
- [ ] Colour behaves like material rather than UI accent
- [ ] Layering, pressure, overlap or accumulation are visible where appropriate
- [ ] Colour is controlled rather than everywhere
- [ ] Quiet sections genuinely become quieter

## Theory-specific composition
- [ ] Composition plausibly belongs to this theory
- [ ] No universal hero/cards/diagram template
- [ ] Theory structure affects spatial behaviour

## Annotation
- [ ] Every handwritten note has a reason to exist
- [ ] Notes reveal assumptions, boundaries, questions or relationships
- [ ] Avoids filler such as “important” or “remember this”

## Quiet scholarship
- [ ] Evidence remains rigorous and inspectable
- [ ] Scope and Limitations are visible without generic cards
- [ ] Provenance is understandable
- [ ] Sources and References remain easy to use
- [ ] Quiet sections still feel like Concept Lab

## Material authenticity
- [ ] Pencil looks varied rather than procedurally repetitive
- [ ] Hatching, smudging, erasure, overlap, contour and ghost marks are selective
- [ ] Page avoids an all-hatching or all-SVG-engine look
- [ ] Result feels artistic enough

## Anti-patterns
- [ ] Not SaaS
- [ ] Not dashboard
- [ ] Not generic editorial portfolio
- [ ] Not card-grid website
- [ ] Not scrapbook
- [ ] Not sticky-note theme
- [ ] Not beige notebook
- [ ] Not children’s educational graphics
- [ ] Not decorative doodle layer
- [ ] Not repeated left-copy/right-image layout

## Final questions

> **If someone saw this page without the logo, would they recognise that it belongs to the same visual world as the best Academic Concept Lab references?**

> **Does this feel like a page for thinking with theory, rather than a page that merely explains theory?**

## Art / code balance

- [ ] Is a complex expressive image being forced into procedural SVG unnecessarily?
- [ ] Would a generated/authored art asset carry the intended material quality better?
- [ ] Is code being used mainly where structure, behaviour, responsiveness, or interaction requires it?
- [ ] Does the final page avoid looking like a technical diagram system merely because it was coded?
