# Academic Concept Lab — style-neutral semantic handoff

This package is the Phase A handoff for a future visual exploration. It is a
knowledge and interaction specification, not a visual redesign brief.

## Scope

The repository remains the source of truth for academic meaning. This package
extracts the semantic contract of four music-psychology records:

- Gestalt Principles in Music
- Tonal Hierarchy
- Predictive Processing in Music
- Huron’s ITPRA Theory of Expectation

It also defines the scholarly apparatus and interaction intentions that must
survive any later presentation work.
