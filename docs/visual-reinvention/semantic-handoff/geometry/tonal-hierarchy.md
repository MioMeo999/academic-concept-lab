# Style-neutral geometry: Tonal Hierarchy

This is an abstract knowledge geometry, not a drawing brief.

## Primary structure

`tonal context × pitch → contextual role / relative fit`

## Measurement path

`context → probe → fit judgment → repeated profile → psychological inference`

The measurement path must not be mistaken for a full processing mechanism.

## Relationality

A pitch’s function is relational to its tonal context. The same pitch can be a
tonic, tonic-triad member, other diatonic tone, or nondiatonic tone depending on
the context.

## Hierarchy and dimensions

The record contains several intersecting dimensions rather than one line:

- tonic anchor
- other tonic-triad relations
- other diatonic relations
- nondiatonic relations
- pitch height
- chroma/octave equivalence
- key-to-key similarity

## Temporality and recurrence

Successive chords update the balance among possible tonal interpretations.
Earlier context remains relevant; new context can strengthen, weaken, or
replace an interpretation. The profile is a snapshot/representation boundary,
not the whole temporal process.

## Feedback / update

`new musical context ↔ updated tonal organisation`

This is a conceptual update relation. It does not specify a single algorithm.

## Ambiguity and conflict

Competing key regions can remain active. Profile similarity, local context,
distribution, experience, and culture need not determine one interpretation in
the same way.

## Context dependence

Immediate musical structure and learned/cultural organisation jointly matter.
The C-major teaching context is not a universal default.

## Core transformation

An undifferentiated pitch becomes a context-dependent tonal function, and local
profiles can be related into psychological key neighbourhoods.

## Core relational problem

How can a psychological profile of tonal fit be represented without confusing it
with liking, physical pitch, probability, or the complete key-finding process?

## Invariants for future presentation

Preserve the three-level distinction—judgment, profile, interpretation—the
contextual role of a held probe, the non-literal key space, dynamic updating,
and cultural/developmental limits.
