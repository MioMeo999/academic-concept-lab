# Style-neutral geometry: Huron’s ITPRA Theory

This is an abstract knowledge geometry, not a drawing brief.

## Primary structure

`expectation sources → pre-outcome preparation → outcome hinge → post-outcome
parallel questions → slower appraisal`

## Relationality

The same outcome can be evaluated for predictive accuracy, immediate functional
response, and broader significance. These are different questions about one
event, not one scalar feeling.

## Hierarchy and temporality

Imagination reaches furthest back; Tension approaches the outcome; Prediction
and Reaction begin together after onset; Appraisal extends later and can recur.

The temporal ordering is functional and approximate. It is not an algorithm or
a neural trace.

## Feedback / revision

`later context → appraisal → confirm / revise / reverse earlier interpretation`

Appraisal can change the meaning of the same outcome without erasing the prior
prediction or reaction.

## Ambiguity and conflict

Expectation sources can operate concurrently and conflict: an event can be
veridically expected and schematically unexpected. Initial predictive/reactive
valence can differ from later appraisal.

## Context dependence

Social, environmental, personal, musical, stylistic, work-specific, dynamic,
and conscious knowledge can contribute to expectation and appraisal.

## Core transformation

One anticipated outcome becomes multiple temporally distinct functional
questions: what might happen, how to prepare, how accurate the forecast was,
what to do now, and what the event means later.

## Core relational problem

How can expectation-related experience contain different timescales and
functions without collapsing into a single feeling or overclaiming five
independent biological modules?

## Invariants for future presentation

Preserve the outcome hinge, P/R parallelism, slower appraisal, the expectation
source layer, contrastive-valence qualification, and the distinction between
theory, evidence, and safe constructed examples.
