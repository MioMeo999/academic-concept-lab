# Style-neutral geometry: Predictive Processing in Music

This is an abstract knowledge geometry, not a drawing brief.

## Primary structure

`experience + current context → generative model → prediction ↔ input`

## Error and weighting

`prediction − input → mismatch × precision → inference / learning / attention /
action`

The multiplication symbol denotes influence weighting in the teaching model,
not a claim about one literal operation in every formulation.

## Relationality

Meaning lies in the relation between expected state, actual/represented input,
uncertainty, and the model’s current hypothesis. “Error” is not a moral or
musical value judgement.

## Hierarchy and timescale

Fast/local: acoustic feature, onset, pitch, rhythmic pattern.

Middle: meter, melody, harmony.

Slower/higher: phrase, style, learned context.

These are explanatory levels. They are not assigned anatomical destinations.

## Temporality and recurrence

Prediction precedes or accompanies input; mismatch informs an update; the
updated model generates further predictions. An expected omission is a case
where the predicted event and actual silence diverge.

## Feedback / active sampling

`update → new predictions`; attention and possible action can alter which input
is sampled or weighted. Active inference remains a subordinate extension in the
record.

## Ambiguity and conflict

The same physical deviation can be more or less influential under different
uncertainty assumptions. Signals compatible with predictive accounts can have
multiple computational interpretations.

## Context dependence

Experience, expertise, culture, current musical history, and active listening
shape priors and precision. Culture is not one homogeneous prior.

## Core transformation

Sensory events become evidence relative to a generative hypothesis; mismatches
can update the hypothesis rather than simply interrupt perception.

## Core relational problem

How can a framework make prediction, mismatch, and precision explanatory while
avoiding the claim that every measured response uniquely identifies that
computation?
